## Recommended sizing

| Specification | Value |
| --- | --- |
| AWS Instance Type | `g6e.2xlarge` |
| vCPU | 8 |
| GPU | NVIDIA L40S, 48 GB |
| Memory | 64 GB |
| Storage | 450 GB |

Latency target under load: **≤ 1.5 seconds per message** at the stated concurrency tiers. See [Performance benchmarks](/benchmarks/performance) for per-guardrail numbers.
